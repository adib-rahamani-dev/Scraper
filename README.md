# رادار لید

یک پنل فارسی برای پژوهش سرنخ‌های فروش از آگهی‌های عمومی. در مسیر اصلی فقط موضوع کسب‌وکار وارد می‌شود؛ برنامه برای دیوار، شیپور، ایران‌تجارت و نیازبان لینک جست‌وجو می‌سازد، پروژه‌ها را در صف اجرا قرار می‌دهد، اطلاعات تماس آشکار را استاندارد و تکراری‌ها را حذف می‌کند و نتیجه را در CSV تحویل می‌دهد. حالت پیشرفته برای واردکردن لینک اختصاصی هم باقی مانده است.

## شروع سریع

1. موضوعی مثل «کابینت» یا «دستگاه بسته‌بندی» را در کادر رادار بنویسید.
2. روی «روشن‌کردن رادار» بزنید؛ منابع داخلی خودکار پیدا، ساخته و صف‌بندی می‌شوند.
3. در «پویش‌های انبوه» فقط یک رکورد برای موضوع می‌بینید؛ جزئیات تک‌منبعی پشت‌صحنه می‌ماند.
4. نتیجه پاک‌سازی‌شده و بدون شماره تکراری را با «خروجی یکجای CSV» دریافت کنید.

انتخاب لینک و تنظیمات خزش دستی در «لینک اختصاصی» قرار دارد. مدل داده برای فیلترهای شهر و منطقه آماده است و رابط این فیلترها در نسخه بعدی فعال می‌شود.

## اجرای محلی

```bash
npm install
npm run dev
```

سپس `http://127.0.0.1:5173` را باز کنید. API روی پورت `4300` اجرا می‌شود.

## اصول استفاده

- فقط صفحات عمومی و قابل دسترس بدون ورود بررسی می‌شوند.
- `robots.txt` و محدودیت سرعت هر دامنه رعایت می‌شود.
- هیچ کپچا، ورود، محدودیت دسترسی یا نمایش محافظت‌شده‌ی شماره دور زده نمی‌شود.
- خروجی برای پژوهش B2B و تماس مسئولانه طراحی شده است؛ رعایت قوانین سایت منبع و حق انصراف مخاطب بر عهده استفاده‌کننده است.

## ساختار

- `src/server`: API، SQLite، موتور خزش و استخراج
- `src/web`: داشبورد RTL
- `src/shared`: قراردادهای مشترک
- `tests`: تست‌های استخراج و سیاست URL
